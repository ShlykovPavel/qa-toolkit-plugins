# История выпусков

## 2026.11.18-preview.1

Первый предварительный пользовательский комплект под MIT:

- `qa` 0.2.34 — ядро QA-проекта и база знаний.
- `qa-manual` 0.1.5 — ручные проверки и оформление находок.
- `qa-auto` 0.1.17 — автотесты API, веба и мобильных приложений.
- Готовые каталоги Claude Code и Codex; переносимые процедуры для ручного подключения в других агентах.
- Инструкция для человека и ИИ-агента, манифест файлов и SHA-256 архива.
- Исключены материалы мастерской, лаборатории, skill-lab и размеченные шаги обкатки.

Нативный пакет Antigravity не включён: его валидатор отвергает агента skeptic-evidence.
Переносимые процедуры не подключают хуки автоматически и не гарантируют одинаковой работы всех приложений.
