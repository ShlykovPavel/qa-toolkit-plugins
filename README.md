# QA Toolkit

Скиллы, инструкции для помощников, скрипты и шаблоны для работы QA: база знаний,
ручные проверки, API, веб-интерфейс и мобильные автотесты. Это предварительный выпуск
для совместной работы: поддержка всех сценариев во всех ИИ-приложениях не заявляется.

## Что скачать

Скачайте прикреплённый к выпуску архив `qa-toolkit-<версия>.zip` и `SHA256SUMS`
из [Releases](https://github.com/ShlykovPavel/qa-toolkit-plugins/releases).
Проверьте архив командой `shasum -a 256 -c SHA256SUMS` (macOS) или
`sha256sum -c SHA256SUMS` (Linux), затем распакуйте его в постоянную папку.
Автоматический архив GitHub «Source code» не является пользовательской сборкой.

Можно передать эти два файла коллеге напрямую, без доступа к приватной мастерской.
В архиве нет истории Git, тестов мастерской, результатов прогонов и лабораторных материалов.
Тесты внутри шаблона проекта оставлены: это примеры для будущего QA-проекта.

## Что внутри

| Папка | Назначение |
|---|---|
| `portable/` | Общие процедуры и скрипты: интеграция в другие агенты с доступом к файлам и терминалу |
| `claude/` | Готовый локальный каталог плагинов Claude Code |
| `codex/` | Готовый локальный каталог плагинов Codex |

Во всех вариантах есть `qa` (ядро), `qa-manual` (ручные проверки) и `qa-auto` (автотесты).
Устанавливайте один подходящий вариант. Не загружайте все три копии скиллов в один чат.
Python 3.11+ нужен для скриптов. Git, браузерные инструменты и зависимости тестового
проекта нужны по выбранному сценарию; API-ключи и доступы в архив не входят.
Приведённые команды рассчитаны на macOS/Linux; на Windows используйте WSL.

## Быстрая установка

Если этот репозиторий уже опубликован, Claude Code также может установить пакеты напрямую:

```sh
claude plugin marketplace add ShlykovPavel/qa-toolkit-plugins
claude plugin install qa@qa-toolkit
claude plugin install qa-manual@qa-toolkit
claude plugin install qa-auto@qa-toolkit
```

Из распакованной папки `qa-toolkit` для Claude Code:

```sh
claude plugin marketplace add "$PWD/claude"
claude plugin install qa@qa-toolkit
claude plugin install qa-manual@qa-toolkit
claude plugin install qa-auto@qa-toolkit
```

Для Codex:

```sh
codex plugin marketplace add "$PWD/codex"
codex plugin add qa@qa-toolkit-codex
codex plugin add qa-manual@qa-toolkit-codex
codex plugin add qa-auto@qa-toolkit-codex
```

Это установка на уровне пользователя. После неё начните новый чат и проверьте
разрешения хуков в приложении; не обходите проверку доверия.
Попросите выполнить скилл `qa:hello`: ожидается `QA-HELLO-OK qa v0.2.34`.
Если CLI приложения не поддерживает эти команды, используйте его механизм установки
локальных плагинов; не меняйте вручную внутренний кэш приложения.

Для другого агента дайте ему файл `INSTALL_FOR_AGENTS.md` из этого архива.
`portable/` не является автоматически устанавливаемым плагином для любого ИИ:
подключение скиллов зависит от приложения, а хуки и настройки проекта требуют адаптации.
Подключайте скиллы с сохранением всей папки `portable/`, включая соседние пакеты и скрипты.
В чате без доступа к файлам и терминалу полноценная работа скриптов невозможна.

## Журналы и обновление

В нативных пакетах сохранены хуки QA-проектов. Они могут сохранять выжимки сессий
в `.qa/labs/` проекта и добавлять эти файлы в индекс Git; сами не делают commit или push.
Для отключения сбора укажите `lab: off` в `.qa/project.yaml` соответствующего QA-репозитория.
Перед передачей журналов проверьте их содержимое.

Каждый выпуск содержит свои версии плагинов и контрольные суммы в `release.json`.
Обновляйте из нового архива, следуя его инструкции. Автоматическое обновление из
приватной мастерской не требуется. Настройки создаваемого QA-проекта, которые предлагают
каталог GitHub, согласуйте с выбранным приложением: архив не настраивает удалённый каталог.
