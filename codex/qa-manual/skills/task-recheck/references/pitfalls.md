# Копилка граблей: чек-лист перед сдачей

Каждый пункт однажды дал ложный результат. Прогоняй список перед тем, как отдать отчёт — и
перед тем, как назвать что-то багом.

## Про доказательность выводов

| Грабли | Симптом | Противоядие |
|---|---|---|
| Вакуумные проверки | «✓» на пустой выборке | Число записей рядом с вердиктом. **Лучше — отдельная проверка «выборка непуста»** перед содержательными: она краснеет там, где остальные молча зеленеют |
| Выборка в одну запись | обе ветки условия «пройдены», хотя наблюдалась одна | Назвать явно: «на 1 записи различие между ветками ненаблюдаемо» |
| Зелёный отчёт как доказательство | сводка вместо данных | Посмотреть фактические тела ответов глазами, а не сводку прогона |
| Самореферентная проверка | сравнение с переменной, захваченной в том же прогоне | Перепроверить состояние независимым чтением, вне цепочки |
| Маскировка секрета | `Bearer ****` принят за отсутствие токена | Судить по коду ответа и телу, а не по виду заголовка |
| Ложные совпадения поиска | `grep` нашёл слово в названии, а не в теле | Считать по телу проверок; поиск — только чтобы найти место |
| Скрипт из документа не запускался | «готовый, копируется как есть», а он падает | Выполнить прямо из документа и вставить фактический вывод |
| Текстовый поиск по SVG-иконке | «×» не найден, хотя кнопка на экране есть | Структурный DOM-запрос (`aria-label`, имя узла), а не `innerText` |
| «Система не умеет X» без попытки | оговорка о границах прошла как факт: её не выглядит нужным проверять, а весит она столько же — именно она объясняет, чего заход не сделал | Фраза «не умеет / не отдаёт / не поддерживает» проверяется одним вызовом **раньше**, чем пишется, если вызов вообще возможен |
| Отрицательный вывод шире поля зрения | «не воспроизводится», «механизм не сработал» — про твой заход, а поданы про мир | Две сверки до написания: свежие соседние записи и прогоны того же дня (параллельная сессия могла снять ровно это); и запрос, которым проверяли, обязан проходить **все прочие** проверки, кроме собственно проверяемой — иначе сервер до неё не дошёл, и это не наблюдение, а его отсутствие |
| `mtime` как доказательство порядка | «между наблюдением A и B такого-то действия не было» — на метках файлов, которые в заходе дописывались | Порядок событий доказывай **порядком вызовов инструментов внутри разговора**: он не меняется правками на диске. `mtime` годится, только если ни один из сравниваемых файлов после первой записи не правился — то есть почти никогда |

## Про источники

| Грабли | Симптом | Противоядие |
|---|---|---|
| Пересказ вместо первоисточника | «сделано» вместо «покрыто 3 из 6» | Два источника: первоисточник и база знаний, всегда оба |
| Критерии только в описании | половина критериев не найдена | Читать **и комментарии**: там они бывают целиком |
| Границы объёма не выписаны | чужая недоделка записана как дефект этой задачи | Выписать, что автор явно вынес в другие задачи |
| Заголовок вместо содержания | неверная классификация на старте | Классифицировать по критериям, а не по названию задачи |
| Отставший снапшот спеки | «поля нет, значит не сделано» | Сверить снапшот с живой спекой до выводов |
| Доверие помощнику | план построен на чужой выжимке | Перепроверять ключевые утверждения своими руками |
| Класс учётки или данных взят из заметки | «первая подача, никогда не одобрена» — а её одобрили шесть дней назад | Заметка верна **на дату записи**: свойство, на котором стоит вердикт, перечитывается живым запросом |
| Файл специфики стенда прочитан выборочно | известная механика (ленивый рендер, кеш) пропущена, находка ложная | Читать целиком перед первым наблюдением на фронте, а не `grep`-ом по своей гипотезе |
| Домен-факт взят с соседнего агрегата | поле сводки или дашборда подошло по имени и непусто | Факт («реквизиты заполнены», «почта подтверждена», «модерация пройдена») берётся с эндпоинта **самой сущности**: агрегаты денормализуют по своей логике и расходятся с источником и по смыслу, и по свежести |
| «Вчера» по ощущению порядка сессий | заходов несколько за календарный день, разница в часах, а не в сутках — а на ней стоит довод «билд не менялся» | Величина, которую легко прочитать в удобном месте, проверяется там, где она **первична**: дата — `git log` или шапка файла предыдущего захода, а не память о порядке |

## Про инструмент

| Грабли | Симптом | Противоядие |
|---|---|---|
| Переменная прочитана не тем способом | `undefined` в коде при живом значении в URL | Знать идиому своего раннера; проверять, что подстановка произошла |
| Переменные не переносятся между запусками | пустой токен, `401` | Логин и запрос — одной командой |
| Осиротевшая переменная | часть запросов молча ушла анонимно | После правки логинов — поиск по ссылкам на переменную |
| Порядок в цепочке | `404` на ровном месте | Цепные запросы гнать целой папкой, не вразнобой |
| Проба не применилась | мутация есть, а запросы те же | Сравнить запросы до и после подмены; не изменились — результат недействителен |
| Рукотворный дамп без шапки | число приписано не тому файлу — трижды за один заход | Запросы гнать через `${PLUGIN_ROOT}/bin/evidence.py run`; одиночный `curl` — только с шапкой: время, URL, учётка, канал |
| Перепечатка вывода браузерного инструмента | элементы теряются, размер в байтах выдан за длину текста | Raw-вывод в файл следующим же действием, разбор — вторым файлом |
| Наблюдение живёт только в сессии | лог виден глазами, сессия оборвалась — подтверждения нет | Решающее наблюдение сохраняется немедленно, до доборов и правок |

## Про передачу человеку

| Грабли | Симптом | Противоядие |
|---|---|---|
| Изменения стенда не задекларированы | тестировщик наткнулся сам | Раздел «что изменилось на стенде» — всегда, даже если всё откатилось |
| Тихое сужение | критерий выпал, не назван непокрытым | Сверить список критериев со строками отчёта один к одному |
| Разведка подана как результат | «проверено 17 пунктов», из них половина — осмотр | Разделять «наблюдал» и «осматривал поверхность» |
| Ответ человека не записан | следующая сессия задаёт тот же вопрос | Правило — в базу знаний, «так задумано» — в файл специфики, **в тот же заход** |
| Вопросы по одному | три остановки вместо одной | Копить в пакет и отдавать вместе с планом |
| Догадка вместо вопроса | «вероятно, работает так» | Факт ищешь сам, решение спрашиваешь. Не нашёл — вопрос, а не гипотеза |

## Последняя проверка, одной строкой

Перед сдачей ответь себе: **какое наблюдение я предъявлю на каждое слово «покрыт»?**
Ответа нет хотя бы на одно — отчёт не готов.
