# Поиск по репозиторию и работа со спекой API

> Открывай, **когда собираешься искать по файлам или лезть в спеку** (сваггер/OpenAPI):
> здесь ограничения на `Grep`/`Glob`, готовые выборки по спеке и правило про снапшот.
> Пути спек этого проекта — не здесь, а в разделе 1 `project-passport.md` проекта.

Правило поиска стоит в `SKILL.md` этого скилла и здесь не повторяется: `Grep`/`Glob`
всегда с `path` внутрь страниц вики (`pages` у `${PLUGIN_ROOT}/bin/qa-paths`) или на конкретный каталог, поиск
шире одного каталога — помощнику. Ниже — только работа со спекой.

**Спека API (сваггер/OpenAPI) — машинный справочник, целиком не открывать никогда.**

Сколько на проекте спек (бывает отдельно user/admin API), их пути в `raw/`, адреса живых
спек на стенде и дата снапшота — строка «Спецификация» раздела 1
`project-passport.md`. Не нашёл её заполненной — спроси
человека, а не ищи файл спеки перебором по репозиторию.

Готовые выборки (`<raw>` — `${PLUGIN_ROOT}/bin/qa-paths raw`, сырьё вики):

```bash
# пути раздела
python3 -c "import json;s=json.load(open('<raw>/<спека>.json'));print('\n'.join(p for p in s['paths'] if '<Раздел>' in p))"
# схема по имени
python3 -c "import json;s=json.load(open('<raw>/<спека>.json'));print(json.dumps(s['components']['schemas']['<Schema>'],ensure_ascii=False,indent=1))"
```

Не писать `jq '.paths'` и подобное — выльет сотню килобайт. Если снапшот минифицирован в
одну строку, `grep` по нему запрещён: только `python3`/`jq`.

**Снапшот врёт быстрее, чем кажется.** Контракт на бэкенде мог измениться после того, как
снапшот выгружен. Перед выводом «поля нет / ручки нет» дёрнуть живую спеку `curl`-ом и
сверить — это один шаг.

**Решение, стоит рассмотреть для снапшотов спеки:** заменять файл, а не копить версии —
приехал новый снапшот с датой, старый удаляется тем же коммитом, в базе всегда ровно один
снапшот на спеку. Неактуальный контракт рядом с актуальным даёт ложные выводы, а история
git и так помнит файл. Что нужно сохранить руками, если так решите, — **дельту**, в раздел
«История снапшотов» на странице соответствующего источника. Так же можно решить про
отслеживаемые выгрузки внешней вики (документ, который часто правят) — порядок в `qa:kb-ingest`,
раздел «`raw/` неизменяем». Прочие источники не трогать.
