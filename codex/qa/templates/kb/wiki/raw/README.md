# raw/ — источники

Сюда кладём источники. Всё в этой папке **неизменяемо**: LLM читает, но не правит и не
удаляет. Это источник истины базы.

## Что складывать

Выгрузки внешней вики (ТЗ, спеки флоу, продуктовые документы), status-страницы бэкенда и
фронтенда, дизайн-доки, UX-требования, макеты отчётов, переписку с решениями PO/PM,
снапшоты API-спеки (сваггер/OpenAPI и т.п.).

## Имена файлов

`<тема>-<уточнение>.md`, латиницей или транслитом, kebab-case, например:

```
project-status-<продукт>.md
moderation-flow-<флоу>.md
swagger-<api>-<дата>.json
```

## Что обязательно сохранять в тексте

База разрешает конфликты между источниками **по дате**, поэтому при выгрузке важно не
потерять:

- **дату документа** и дату последнего изменения;
- **статус**: `AS-IS` (описывает как есть) или `TO-BE` (целевое состояние);
- **пометки** `[exists]` / `[gap]` / `[verify]` — они переносятся в вики как есть;
- **номера задач трекера** и MR — вики ссылается на них, а не на пересказ.

Без даты и статуса источник почти бесполезен: часть документов в наборе может отменять
решения другой части.

## Картинки

Вложения — в `raw/assets/`. В Obsidian: Settings → Files and links → Attachment folder
path = `raw/assets`. Хоткей «Download attachments for current file» подтягивает картинки
статьи на диск после клиппинга.

Markdown с инлайн-картинками читается в два прохода — сначала текст, потом отдельно
значимые изображения. Если картинка несёт смысл (макет отчёта, схема, диаграмма
состояний) — скажите, на какую посмотреть.
