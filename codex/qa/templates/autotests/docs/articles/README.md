# Статьи для тестировщика

Полезные материалы, которые не являются рецептами фреймворка (те живут
уровнем выше в `docs/`), а дают контекст и практику: обзоры инструментов,
разборы подходов, шпаргалки.

Отличие от рецептов: рецепт (`docs/api-layer.md`, `docs/tests.md`, ...)
отвечает «как сделать X в этом шаблоне», статья — «что это за инструмент /
подход и стоит ли его брать».

## Как добавлять статью

1. Файл `<тема>.md` в этой папке, язык — русский, стиль — практический
   (что делать и чего не делать, а не пересказ документации).
2. Строка в оглавлении выше: ссылка + один абзац о чём.
3. Если статья дублирует или уточняет рецепт — перекрёстные ссылки в обе
   стороны.
