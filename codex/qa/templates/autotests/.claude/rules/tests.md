# Конвенции тестов: фикстуры и независимость

Правило грузится, когда агент читает файл в `Tests/`. Глубже —
[docs/tests.md](../../docs/tests.md) и [docs/fixtures.md](../../docs/fixtures.md).

## Scope фикстур

- `scope='session'` — только bootstrap авторизации и подготовка окружения.
  **Никогда не создавай здесь тестовые данные**: сессия общая на весь прогон.
- `scope='function'` — все тестовые данные: создание в setup, удаление в
  teardown через `yield`. Удаление терпимо к ошибке, но отказ уборки —
  `report_teardown_failure` (`src/teardown_utils.py`), не `print`: pytest
  глотает stdout прошедших тестов.
- Teardown фикстуры, упавшей ДО `yield`, не выполняется. Есть шаги между
  созданием ресурса и `yield` (поиск id, получение кода, логин) → регистрируй
  ресурс в cleaner сразу после создания или оборачивай эти шаги в
  `try/finally` с удалением.
- Фикстура — только предусловия и teardown. Действие, которое тест
  ПРОВЕРЯЕТ, в conftest не выносится: его падение станет ERROR фикстуры
  вместо FAIL теста.

## Тесты независимы — это проверяемое требование

- Фикстуры ВОЗВРАЩАЮТ значения (`yield resource_id`), тест принимает их
  параметром.
- **Никаких общих словарей для передачи данных между тестами.** Каждый тест
  обязан проходить в любом порядке и параллельно (`pytest-xdist`).
- Данные, созданные прямо в тесте, убираются фикстурой `*_cleaner` — дописывай
  в неё id.

## Данные и ожидания

- Уникальные данные всегда — `src/data_generators.py`.
- Ждать асинхронного распространения — `wait_until()` из `src/wait_utils.py`.
  **Никогда `time.sleep`** — `make verify` падает на нём
  (`scripts/check_no_sleep.py`). Переход, который нечем дождаться по
  идентификатору, гоняй циклом `wait_until` по появлению следующего якоря.

## Эталоны

`Tests/Smoke_tests/` — быстрые happy-path, один класс на фичу.
`Tests/Regression_tests/` — полный CRUD, негативы, многошаговые флоу.
Копируй `example_*`-каталоги, сами эталоны не правь.
