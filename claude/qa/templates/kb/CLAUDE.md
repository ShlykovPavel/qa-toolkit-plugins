<2–3 предложения о продукте.> Вики — единственная точка истины, всё остальное — инструмент
вокруг неё. Проект разворачивается командой `/qa:init` плагина `qa-toolkit`.

```
wiki/              база знаний — ЧТО за продукт и КАК он работает
  raw/               сырьё: выгрузки внешней документации, спеки, сваггер
  wiki/              дистиллят: страницы, написанные по сырью
api_collection/    коллекция запросов — ЧЕМ дёргаем API (инструмент выбирается при инициализации)
```

**Правила работы — скилл `qa:rules`.** Вызови его в начале сессии, до первой работы с вики,
спекой, коллекцией или трекером: там «сам или помощник», поиск, ингест, коммиты по зонам и
политика трекера. Коротко: не знаешь, что искать, — разведчик; сырьё — помощник; дистиллят —
сам, какого бы размера он ни стал.

Обязательные поля `project-passport.md` — **разделы 1 и 8 плюс три строки раздела 2**: без них
скилл `task-recheck` не начинает работу, остальное дозаполняется по ходу. Стенды — в
`site-notes.md`.

## Где специфика проекта

| Файл | Что в нём |
|---|---|
| `project-passport.md` | стенды, спеки, доступы, границы, куда пишутся находки |
| `site-notes.md` | что на этом проекте считается нормой — **сильнее** общих критериев |
| `tracker-passport.md` | трекер: проект, типы, приоритеты, статусы, доска |
| `wiki/CLAUDE.md`, `api_collection/CLAUDE.md` | правила подпроектов — прочитай сам первым заходом в подпроект |

## Трекер

- **Трекер** — какой, формат номера, шаблон URL задачи.
- **Политика доступа к трекеру** — обычно: любое обращение (чтение, поиск, создание, правка,
  комментарий, перевод по стадиям) — по прямой просьбе человека или после его апрува.

## Что где искать

**Пусто по адресу из таблицы — значит «нет».** Не добирай ответ из паспорта, `site-notes.md`
или соседнего подпроекта (см. «Искомого нет» в `qa:rules`).

| Вопрос | Куда |
|---|---|
| Как устроен флоу, статусы, лимиты, правила | `wiki/wiki/flows/`, `wiki/wiki/domain/` |
| Что вообще есть в базе | `wiki/index.md` → нужная страница |
| Где проект сейчас, что блокирует запуск | `wiki/wiki/synthesis.md`, `wiki/wiki/status/` |
| Термин, доменная роль, коды ошибок | `wiki/wiki/glossary.md`, `wiki/wiki/api/` |
| Точный контракт эндпоинта | `wiki/raw/<спека>.json` |
| Чек-листы и тест-кейсы по флоу | `wiki/wiki/tests/test-*.md` |
| Тест-кейсы под карточку трекера | `wiki/wiki/tests/zadachi/test-*.md` |
| Отчёт захода перепроверки, вердикт по дефекту | `wiki/wiki/reports/otchet-<дата>-<что>.md` |
| Что по задаче уже делали, на чём она стоит, смежные задачи | карточки `tasks/<id>.md` — `qa-task list`, `qa-task find <слово>` |
| Живая, более свежая документация (если есть) | см. раздел «Внешняя документация» в `wiki/CLAUDE.md` |
| Готовый запрос к API | `api_collection/<Раздел>/` |

Пути даны от корня репозитория.

## Коммиты: три зоны

Корень (правила и специфика проекта), `wiki/` (база знаний), `api_collection/` (коллекция
запросов). **Коммит никогда не смешивает зоны**; префиксы и порядок — в `qa:rules`.
