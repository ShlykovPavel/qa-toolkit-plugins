# qa-auto

Автотесты: API, фронтенд, мобилка, локаторы, ревью тестового слоя.

This package is part of QA Toolkit. Keep qa, qa-manual and qa-auto together. Install the matching Claude Code or Codex edition using the bundle README, or integrate the portable procedures with your host explicitly. Python 3.11 or newer is required for the bundled helpers. Project dependencies and credentials are configured separately. Read INSTALL_FOR_AGENTS.md before setup. Licensed under MIT; see LICENSE.
