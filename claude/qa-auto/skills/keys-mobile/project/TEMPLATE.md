## Правила ведения (не удалять)

1. **Дублировать сюда содержимое общих доков нельзя.** Карточка держит либо
   факт, которого больше нигде нет, либо указатель. Копия расходится с
   оригиналом — это уже случалось в этом шаблоне дважды.
2. **У каждого факта есть команда пересъёма.** Значение устарело — его
   переснимают командой, а не спорят с документом. Факта без команды в
   карточке быть не должно.
3. **Меняющихся цифр здесь нет.** Объём миграции, число мигрированных узлов,
   прогресс порций живут в проектных доках и снимаются Шагом 1 каждый прогон.
4. **Не установлено — так и пишется**, с командой, которая это выяснит.
   Догадка в карточке хуже пустой строки.

## 3. Подпакеты монорепо

| Пакет | Направление зависимости | Где живёт примитив | Проверено чем |
|---|---|---|---|
| `<packages/…>` | `<lib → пакет / пакет → lib / независимы>` | `<в пакете / в корне / прямой Semantics внутри>` | `grep -n <пакет> -A3 <путь>/pubspec.yaml` (КОРНЕВОЙ) + `grep -rn "package:<корень>" packages/<пакет>/lib` |

Пакетов нет → строка «монорепо без подпакетов».

Направление считается по **корневому** `pubspec.yaml`: пакетный доказывает
только отсутствие обратной зависимости, и вывод «зависимость циклическая»
из него не следует (эта ошибка уже стоила прогона). Корень тянет пакет →
примитив кладётся В ПАКЕТ, обе стороны его импортируют, дублирования нет.
